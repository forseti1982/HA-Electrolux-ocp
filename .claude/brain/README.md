# Das Brain

Langzeitgedächtnis des Projekts. Es beantwortet Fragen, die weder aus dem Code
noch aus dem README hervorgehen: **warum** etwas so ist, was schon einmal
schiefging, und was bewusst offen blieb.

| Datei | Inhalt | Wann anfassen |
|---|---|---|
| `00-architektur.md` | Datenfluss, Coordinator, Token, Entitäten | Struktur ändert sich |
| `10-api-ocp.md` | Die OCP-API: Auth, Status-Codes, Kommando-Container | neue API-Erkenntnis |
| `20-geraete-wissen.md` | Property-Keys, Enums, `# VERIFY`-Stand | Diagnose-Export ausgewertet |
| `30-entscheidungen.md` | Entscheidungs-Protokoll | jede bindende Entscheidung |
| `40-frontend-karten.md` | Karten, ASCII-Vertrag, Cache-Busting | Karten-Arbeit |
| `90-offene-fragen.md` | Backlog, Unstimmigkeiten | laufend |

`00` und `10` werden über `CLAUDE.md` automatisch mitgeladen. Der Rest wird
gezielt gelesen — deshalb dürfen diese Dateien ausführlich sein.

Pflege: Skill `brain-pflegen` (oder `/brain`).
